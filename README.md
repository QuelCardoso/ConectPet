# ?? ConectaPet

Plataforma web full-stack desenvolvida para conectar doadores e voluntários a ONGs de proteção animal verificadas.

## ?? Funcionalidades
- Cadastro e autenticação com JWT e bcrypt
- Consulta e filtragem de ONGs e campanhas
- Doação simulada financeira e de suprimentos
- **Oferta de Serviços Voluntários**: atendimento veterinário, banho/tosa, limpeza de abrigos, etc.
- Acessibilidade: Alto Contraste e integração com **VLibras**

## ??? Tecnologias Utilizadas
- **Backend**: Node.js, Express, SQLite3
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Segurança**: JSON Web Token (JWT), BcryptJS
